## Контрольные вопросы

1. Чем `void`-метод отличается от метода, объявленного с типом возврата (например, `int`)?

void — ничего не возвращает. С типом (int) — возвращает число через return

2. Что происходит с выполнением метода в момент срабатывания `return`?

Сразу заканчивает метод

3. Что такое перегрузка методов и по каким признакам компилятор выбирает нужную перегрузку при вызове?

Одно имя — разные параметры. Компилятор смотрит на аргументы и выбирает подходящий

4. Можно ли перегрузить метод, если у двух версий совпадают все параметры, а различается только тип возвращаемого значения? Почему?

Нет. Компилятор не поймёт, какой вызвать — параметры одинаковые

5. Приведите свой пример (не из этой работы), когда логично разбить один большой кусок кода на два отдельных метода.

ReadInt() — читает число. PrintResult() — печатает. Каждый делает одно

6. Что означает, когда один метод вызывает внутри себя другой метод? Как это связано с идеей переиспользования кода?

Один метод использует другой. Так код не повторяем — написал раз, вызываешь везде
